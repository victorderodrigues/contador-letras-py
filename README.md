# contador-letras-py
Script em Python para contagem e análise de vogais em um texto

Sobre

Desenvolvi esse script em Python com o objetivo de praticar manipulação de strings, estruturas de repetição e dicionários.
O programa recebe um texto digitado pelo usuário e realiza a contagem das vogais presentes, exibindo tanto o total quanto a quantidade individual de cada uma.

O que o programa faz
  Solicita que o usuário digite uma frase ou palavra
  Converte automaticamente o texto para minúsculo
  Conta o total de vogais
  Mostra a quantidade individual de:

    a
    e
    i
    o
    u

  Lista quais vogais foram encontradas
  Verifica se o texto digitado é uma frase ou apenas uma palavra
